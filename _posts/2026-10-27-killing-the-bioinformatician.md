大模型本身只会做一件事：预测下一个词。可一旦给它装上手和脚，比如工具调用、代码执行、软件操作，它能干的活就会超出你的想象。科学研究需要的手脚更特殊一些，湿实验终究要在真实世界里做完。所以不少创业公司在搭全自动的"黑灯实验室"，让 AI 不光想科学问题，还可以亲手做实验、验证答案。干实验对 AI 来说就容易得多，你没看 AI 已经在数学圈杀疯了么。

那么生物医学相关的科研，AI 要给生信研究者打好辅助（全面替代），还缺什么？

我一直是嫌弃垂类 Agent 的，更相信"通用 Agent + 专业工具"这条路。所以我关心的问题是：如果想让 WorkBuddy、DeepSeek Harness 这类通用 Agent 工具毫无障碍地做任何生信研究，我还需要给它们补什么武器？

## 缺的是一台大机器

先看一下生信研究者常常需要做的事情：

- 搭建分析流程，AI 完胜
- 调参数、找 Bug，AI 完胜
- 画科研图表，AI 完胜
- 写论文，AI 完胜

少了一样：高性能计算。假如我想跑一套 WGS 数据分析流程，AI 完全知道怎么做，但它做不了。因为我的电脑没地方放几百 GB 的中间文件，而且序列比对一跑，内存会先爆掉，我自己也别想干别的事了。

这也是我们在《Biomni 远超预期，但我更推荐 ToolUniverse》里着重观察的一点：Agent 平台能不能扛得住重型计算？

学校或公司里已经有服务器的生信人，没有这个烦恼，Agent 可以像人一样登录计算服务器替他们干活。但对学生和独立研究者，这就是个大问题了：

1. **重型计算只是偶尔为之的事**。科研里最耗时间和心力的探索部分，大多建立在重型计算产出的数据矩阵上，个人电脑足够。真正需要大机器的，只是偶尔跑一次的上游流程。
2. **偶尔一次，要的却是大块资源，很难临时找到**。CPU 和内存是主力，特殊情况下还要 GPU 或 FPGA。想从云服务商那里凑齐一套计算和存储，订购和配置极其繁琐，用完还得记得释放，不然账单足以让人破产。

## 我想要的平台是什么样子的？

按上面的痛点，我心目中的平台需要至少满足三条：

1. **个人自助注册，按需付费**。像很多 IT SaaS 服务一样，注册、绑卡或充值，用多少付多少。
2. **公共参考数据可以直接挂载或复制到计算实例**。先从 NCBI 下载、再上传到平台，一定是件痛苦的事。
3. **有完善的 CLI**，能在命令行里上传下载数据、投递 WDL 或 Docker 任务。每家的网页界面学习成本都不低，而 CLI 天然适合 Agent 使用。

这其实就是经典的软件即服务（Software as a Service, SaaS），先看看 SaaS 最成熟的美国有哪些方案。

## 美国的成熟方案，没有一家三条全占

| 平台 | 个人注册 + 按需付费 | 公共参考数据 | CLI 与流程迭代友好度 |
|---|---|---|---|
| Seqera Cloud | ✅ 免费档可自助注册；费率高 | ✅ 直接读 iGenomes 公共桶 | ⚠️ CLI 完善，但只支持 Nextflow |
| AWS HealthOmics | ⚠️ 需要 AWS 账号 | ✅ 不预置，可读公共 S3 桶 | ⚠️ CLI 最完整，但改一次脚本要重新打包，等待时间长 |
| Velsera / Seven Bridges | ❌ 商业版要找销售 | ✅ 自带参考库，复制免费 | ✅ CLI 齐全，改参数重跑方便 |
| Terra | ⚠️ 需要自建 GCP 账户和配额 | ✅ Broad 参考数据免费引用 | ⚠️ 没有统一 CLI，但可自动复用已跑结果 |

可以发现，即便在 SaaS 最成熟的美国，也没有一家能同时满足这三条。这些平台是为机构托管生产级流程设计的，并不打算让"一个人加一个 Agent"随时借一台大机器来用。

## 国内呢？

正思考这个事情，刚好看到华大研究院宣传的 Genpilot x WorkBuddy，号称把数据、算力和工具生态深度打通。

仔细一看，Genpilot 其实是两个东西，只是宣传的时候混为一谈。也许是市场部的人自己没搞清楚，也许是考虑到受众的理解能力，故意简而化之。

一个当然是大模型套壳：把连接器、技能和大模型打包成一个网页。我完全理解为什么要这么做，毕竟这就是大家心目中 AI 应该有的样子，也许可以叫它华大版 Biomni。但对我来说，这部分可以直接扔进垃圾桶。

另一个是 DCS Cloud，真正给他们的智能体提供算力的平台，也就是我们要找的那台大机器。既然 DCS Cloud 能接 WorkBuddy，按同样的原理，其他 Agent 工具应该也能把它用起来。

至于是不是像他们吹的那么厉害，下一篇我们实际上手玩一下。
